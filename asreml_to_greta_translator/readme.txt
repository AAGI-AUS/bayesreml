================================================================================
  asreml_to_greta_translator
  An open-source Bayesian alternative to ASReml mixed models using greta
================================================================================

OVERVIEW
--------
This project provides:
  1. A reference catalogue of 60+ mixed-model formulations aligned to ASReml
     (the GLMM_Model_Formulations_Reference_v5.xlsx spreadsheet).
  2. A synthetic MET dataset generator (plant breeding multi-environment trial).
  3. Hand-crafted greta implementations of all 20 model categories
     (a learning and benchmarking resource).
  4. An automated translator (asreml_to_greta) that takes an ASReml-style
     model specification (fixed/random/rcov formulas) and returns a fitted
     greta model -- the main deliverable for eventual R package development.
  5. A comprehensive test suite for the translator.
  6. A real-data comparison validating the translator against ASReml REML
     estimates on the barrero.maize dataset (agridat package).

Design principle -- INDEXING APPROACH:
  All greta code generated by the translator uses the indexing approach:
  parameters are sized by number of levels (p), not by number of observations
  (N).  E.g., u_geno[geno_id] where u_geno has dim p_geno.  This ensures
  O(p) memory for random effects, which is critical for large agricultural
  datasets.  The spline basis (spl()) is the only intentional exception, where
  a k-column B-spline basis (k << N) is unavoidable.


FILES (in recommended run order)
---------------------------------

  GLMM_Model_Formulations_Reference_v5.xlsx
    Reference document cataloguing 60+ mixed-model formulations across
    20 categories (baseline, random effects, structured G, MET/GxE,
    spatial, splines, multivariate, heterogeneous variance, GLMM,
    genomics, hierarchical, SEM, etc.).
    Each row maps an ASReml formula to greta/lme4/glmmTMB/sommer/mgcv
    equivalents.  Read this first to understand the scope of the project.

  01_generate_data.R
    Generates met_data.rds -- a synthetic N=120 MET dataset with:
      - 10 genotypes x 4 environments x 3 replicates
      - Spatial layout (row/col), temporal columns (y_t1..y_t4)
      - Genomic marker matrix M_geno (50 SNPs), genomic relationship
        matrices G_mat (VanRaden) and A_mat (pedigree-approximated)
      - Multiple response types: yield, trait2, count_y, binary_y,
        prop_y, nb_y, ordinal_y, gamma_y, surv_time
    Run ONCE before using 03_greta_model_showcase.R or 04_test_translator.R.

  02_translator.R
    The core translator function:  asreml_to_greta()
    Accepts ASReml-style model formulas and returns an atg_fit S3 object.

    Usage:
      source("02_translator.R")
      fit <- asreml_to_greta(
        fixed  = yield ~ env,
        random = ~ geno + at(env):geno,
        rcov   = ~ at(env):units,
        data   = dat
      )
      print(fit)        # convergence summary
      summary(fit)      # posterior statistics
      coef(fit)         # posterior means
      fit$code          # inspect generated greta code
      fit$draws         # mcmc.list -- works with all coda functions

    Supported ASReml syntax:
      Fixed:   intercept, numeric covariates, factor main effects,
               factor:factor interactions (factor_interaction type)
      Random:  simple (~geno), crossed (~geno+env), nested (block:rep),
               at(env):geno, us(env):id(geno), fa(env,k):id(geno),
               vm(geno, Gmat), ar1(row):id(col), spl(x_cov),
               three-way combos (rep:loc:year)
      Rcov:    ~ units (iid), ~ at(env):units (heterogeneous by env),
               ~ ar1(row):id(col) (spatial), ~ dsum(~ units|env)
      Family:  gaussian, poisson, binomial, gamma, beta, negative_binomial

    Key parameters:
      n_samples   -- posterior samples per chain (default 500)
      warmup      -- HMC warmup steps (default 200; use 1000-3000 for
                     large models with many random-effect levels)
      chains      -- number of MCMC chains (default 2)
      prior_vc_sd -- lognormal(0, prior_vc_sd) prior on all sigma parameters
                     (default 1.0; use 0.5 for large models to reduce
                     prior pull from lognormal mean ~1.65 to ~1.13)
      mcmc_verbose  -- print greta MCMC progress (default TRUE)
      return_code -- if TRUE, return generated code string only (no MCMC)

    Return value (atg_fit list):
      $model        greta_model object
      $draws        mcmc.list (raw samples)
      $greta_arrays named list of all greta arrays in the eval env
      $summary      summary($draws) -- means, SDs, quantiles
      $convergence  list(n_eff, gelman) -- ESS and Gelman-Rubin Rhat
      $code         complete generated greta R code string
      $param_names  character vector of parameters in the model
      $parse_info   parsed formula structure
      $call_info    all original arguments
      $run_time     MCMC elapsed time in seconds
      $env          evaluation environment

  03_greta_model_showcase.R
    Hand-crafted greta implementations of all 60+ models from the reference
    spreadsheet.  These are the TARGET representations: they demonstrate how
    each ASReml model category maps to greta, written by a domain expert.
    They do NOT use the translator -- they are independent reference code.

    Prerequisite: run 01_generate_data.R first (met_data.rds must exist).
    MCMC settings are kept small (n_samples=500, warmup=200) for speed.
    All 60 sections pass.

  04_test_translator.R
    Automated test suite for 02_translator.R.  26 tests covering:

    Section 2 -- Code-generation / indexing tests (return_code=TRUE, fast):
      CG-1a/b   Intercept and factor fixed effects use indexing, not %*%
      CG-2a/b   Simple and crossed random effects
      CG-3a     vm() genomic random effect (Cholesky of known matrix)
      CG-4a/b/c MET structures: at(), us(), fa()
      CG-5a     Spatial AR1 residual structure
      CG-6a     Spline: B-spline basis confirmed (k=8 << N)
      CG-8a     Heterogeneous residual variances at(env):units
      CG-10d    Nested and block terms use precomputed IDs (not factor(paste))

    Section 3 -- Parameter-dimension tests (MCMC with 10 samples):
      DIM-1b    alpha_env dimension == n_env
      DIM-2a/b  sigma_geno, sigma_env in param_names
      DIM-4a    geno x env interaction matrix dimensions
      DIM-8a    sigma_e_atg dimension == n_env
      DIM-ALL   summary row count matches param_names length

    Section 4 -- Scalability smoke tests (N=2000, no MCMC):
      SCALE-1   Code generation for N=2000 completes in < 2 seconds
      SCALE-2   No N-sized parameter arrays in generated code

    Section 5 -- Error / edge-case tests:
      ERR-1   Unknown family raises error
      ERR-2   vm() with missing known matrix raises error
      ERR-3   Response variable not in data raises error
      ERR-4   return_code=TRUE returns a character string
      ERR-5   fa(env,0) zero-factor FA raises error

  05_compare_barrero.R
    Real-data validation of the translator against ASReml REML estimates
    using the barrero.maize dataset (agridat package).

    Model:
      fixed:    yield ~ loc + yearf + loc:yearf
      random:   ~ gen + rep:loc:yearf + gen:yearf + gen:loc + gen:loc:yearf
      residual: ~ dsum(~ units|env)   (heterogeneous error per environment)

    This is a deliberately challenging model:
      - ~4,700 random-effect levels (847 gen + 428 rep:loc:yearf + 3426 gen:loc:yearf)
      - Near non-identifiability between crossed random-effect structures
      - 107 heterogeneous residual variances

    MCMC settings used (tuned for this model):
      SMPL = 2000, WARM = 3000, CH = 2, PRIOR_VC_SD = 0.5

    Results (validated):
      Residual sigmas:  Pearson r = 0.998, MAD = 0.019 (greta vs ASReml)
      gen sigma:        greta 0.68, ASReml 0.71  (4% difference)
      Rhat:             most params < 1.05; gen near 1.0
      (Note: rep:loc:yearf and gen:loc:yearf may need longer warmup
       if Rhat > 1.1 -- increase WARM to 5000 for production runs)

    Output: compare_barrero_greta_asreml_pvc0.5_w3000.pdf


HOW TO RUN (step-by-step)
--------------------------

  Step 0 -- Install dependencies (once):
    install.packages(c("greta", "coda", "ggplot2", "patchwork", "agridat",
                       "data.table", "asreml"))
    greta::install_greta_deps()   # installs TensorFlow + Python env

  Step 1 -- Set working directory:
    setwd("path/to/asreml_to_greta_translator/")

  Step 2 -- Generate synthetic data (once):
    source("01_generate_data.R")
    # Creates: met_data.rds

  Step 3 -- Run the model showcase (optional, slow):
    source("03_greta_model_showcase.R")
    # Fits 60+ greta models; each section runs independently

  Step 4 -- Run the translator test suite:
    source("04_test_translator.R")
    # Expected: all 26 tests PASS, 0 failures

  Step 5 -- Run the real-data comparison (slow: ~30-60 min):
    source("05_compare_barrero.R")
    # Requires: asreml licence and agridat package
    # Output: compare_barrero_greta_asreml_pvc0.5_w3000.pdf


CONSISTENCY NOTES
-----------------
All cross-file dependencies have been verified:
  - 04_test_translator.R and 05_compare_barrero.R both source 02_translator.R
  - 03_greta_model_showcase.R and 04_test_translator.R both read met_data.rds
  - 05_compare_barrero.R uses agridat::barrero.maize (no local data file)
  - The reference Excel name in file headers has been updated from
    "v5_corrected" to "v5" to match the file in this folder

Issues addressed during development:
  - Nested ID computation moved from generated code to setup environment
    (avoids redundant factor(paste()) calls inside the greta model)
  - factor:factor fixed interactions handled via combined integer ID
    (loc:yearf creates a single alpha_loc_yearf[loc_yearf_id] parameter)
  - Three-way random terms (rep:loc:yearf) handled via precomputed combo ID
  - dsum(~ units|env) rcov syntax parsed by detecting the internal ~ call
  - greta::mcmc() verbosity controlled by mcmc_verbose parameter
  - ERR-2/3/5: missing matrix, missing response variable, zero-factor FA
    now raise informative errors instead of failing silently


FUTURE DEVELOPMENT: R PACKAGE
-------------------------------
This project is structured for straightforward conversion to an R package.
Planned package structure:

  R/
    translator.R      <- 02_translator.R (rename asreml_to_greta to atg_fit)
    internals.R       <- all .atg_* helper functions (not exported)
    methods.R         <- S3 methods: print.atg_fit, summary.atg_fit, coef.atg_fit
  man/
    asreml_to_greta.Rd  <- roxygen2 documentation (already present in source)
  data/
    met_data.rda      <- built-in example dataset (from 01_generate_data.R)
  inst/examples/
    03_greta_model_showcase.R
    05_compare_barrero.R
  tests/testthat/
    test_translator.R <- 04_test_translator.R converted to testthat framework
  vignettes/
    introduction.Rmd  <- getting-started vignette using met_data

Key package decisions to make:
  - greta is not on CRAN (TensorFlow dependency); package will need
    Suggests: greta rather than Imports: greta, with conditional execution
  - Consider adding lme4/glmmTMB as alternative backends
  - mcmc.list output is compatible with bayesplot and posterior packages
